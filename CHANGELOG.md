# Changelog

Newest first. Each section says what changed, in plain words.

## 2026-11-20: Repository standards

Adds the working structure the repo was missing: rules for agents, a lessons system, coding standards and checks. The kit's behaviour is unchanged.

- **CLAUDE.md and AGENTS.md** at the root: the product, seven numbered rules that must not break, commands, layout, and the way of working (planning, lessons, branches, the every-change checklist).
- **Lessons system**: `docs/LESSONS.md` routes each area to its lesson file (`docs/lessons/general.md`, `docs/lessons/kit.md`, and the suite's existing `QA-LESSONS.md`) and holds an index generated by `npm run lessons`.
- **Checks**: `npm run check` validates every lesson, checks that every code file has a header comment and every export a JSDoc comment, runs the secret-reads hook against every deny rule (and against harmless commands), and runs `qa-ledger --check`. No dependencies.
- **Comments**: header comments and JSDoc added to the suite's page objects, login helper, config and smoke spec; `node:` prefix and `import type` where they apply. The suite's `CLAUDE.md` now states the comment convention.
- **Suite**: `npm run typecheck` added. `test-index.md` regenerated (the smoke test's line number moved).
- **Docs**: `docs/CODING-STANDARDS.md`, `docs/context/project-history.md`, `docs/README.md`. The README's documentation guide and layout list them.
