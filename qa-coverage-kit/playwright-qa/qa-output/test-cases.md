# Test Cases

> Prose for test cases with **no automation** (blocked on test data, manual-only). An automated test's record is its spec — docstring and code — and `test-index.md` lists every test. IDs follow `playwright-qa/CLAUDE.md` → Identifiers and are never reused. `qa-ledger` reads the `### <ID>: <title>` headings below, and the optional `**Ticket**`, `**Type**` and `**Priority**` lines.
